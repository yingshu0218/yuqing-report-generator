# 舆情分析报告生成器 (Yuqing Report Generator)

> 面向通用 AI Agent 的专业舆情分析报告生成 Skill

## 简介

专为**舆情监测与分析**场景设计的 AI Skill，充当资深舆情分析师。

输入话题关键词，自动检索权威媒体信息源（S 级官方媒体 / A 级权威商业媒体），输出一篇**符合官方媒体风格的舆情分析报告** + **信源与数据解读说明**。

若未指定话题，自动列出近期具有舆情讨论度的热门新闻标题，供用户选择后生成报告。

## 功能特性

- ✅ **自动检索**：5 个维度检索权威媒体信源（新华社、人民日报、澎湃、财新等）
- ✅ **信息核验**：关键事实要求 2 个以上独立来源交叉核验
- ✅ **政务简报风格**：标题→来源行→正文（一是/二是/三是）→参考链接，政务简报+智库观察双重质感
- ✅ **来源追踪**：所有引用数据/观点标注媒体来源
- ✅ **双文档输出**：舆情报告 + 信源与数据解读说明（含逐句溯源表）
- ✅ **热门话题发现**：无指定话题时自动发现近7天热门舆情供选择
- ✅ **满意度确认**：生成后预览确认，支持按反馈多轮调整
- ✅ **通用 Agent 适配**：详细信源、议题和风格规则拆分到 `references/`，便于 opencode、reasonix、WorkBuddy、Codex 等 Agent 读取
- ✅ **多格式导出**：
  - **Markdown**：默认导出两份 `.md` 文件，内容与预览一致
  - **DOCX**：符合标准公文排版（标题黑体小三/正文仿宋四号/首行缩进2字符/单倍行距）

## 输出文档

### 📄 舆情分析报告（`舆情报告_[话题]_[日期].md`）

```
[话题标题]
来源：媒体A 媒体B 媒体C

近日，[事件核心事实]。舆情焦点集中在三条链路：一是……二是……三是……

参考文章及链接：

## 1. [文章完整标题]
[URL]
来源：[站点名称]

## 2. [文章完整标题]
[URL]
来源：[站点名称]
```

### 📊 信源与数据解读说明（`信源与数据解读_[话题]_[日期].md`）

- 报告概览（议题类型 / 检索时间范围 / 信源总数 / 核验状态）
- 报告正文逐句溯源
- 关键数据核查表
- 网友观点采样说明
- 信息缺口说明
- 信源构成整体评估

## 使用示例

**完整流程：**

1. 指定话题 → 自动检索信源 → 生成预览 → 确认满意 → 默认导出 Markdown，可选 DOCX
2. 不指定话题 → 列热门候选 → 选择话题 → 生成预览 → 确认满意 → 默认导出 Markdown，可选 DOCX

**指定话题：**

```
生成一篇关于"房东税"的舆情报告
```

**不指定话题：**

```
帮我生成一篇舆情报告
```

→ Skill 自动列出5-8个近期热门舆情话题，选择后生成报告。

**调整与导出：**

```
满意 → 导出为 DOCX
```

## 信息来源规范

| 优先级 | 来源类型 | 示例 |
|--------|----------|------|
| S 级 | 官方媒体、政府官网、官方通讯社 | 人民日报、新华社、央视新闻、中国政府网 |
| A 级 | 经核验的权威商业媒体和专业媒体 | 澎湃新闻、财新、第一财经、法治日报 |
| B 级 | 经核验官方媒体账号的网络新闻平台 | 网易新闻、腾讯新闻、新浪新闻 |
| 禁止 | 自媒体、营销号、匿名信源、无出处内容 | 今日头条、百家号、搜狐号、网易号 |

完整规则见 `references/source_rules.md`。
