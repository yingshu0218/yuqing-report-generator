# 议题类型、写作风格与敏感表述

> 版本：v1.6.0

本文件用于判断议题类型、选择报告结构、处理敏感表述和统一写作风格。
正式撰写报告前应读取本文件；涉及港澳台、司法案件、民族宗教、公共
安全、涉外议题等时必须读取。

## 报告写作风格

- 语言：书面语、政务简报风，客观、简练、克制。
- 结构：标题、来源行、正文、参考文章及链接。
- 正文：连贯段落，不使用一级/二级标题切割正文。
- 分析：用“一是…二是…三是…”展开，避免只罗列新闻事实。
- 引语：网友观点用带引号短句，仅呈现舆论倾向。
- 数字：一律使用阿拉伯数字，含明确单位。
- 称谓：同一报告内对当事人称谓保持一致。
- 避免：网络流行语、情绪化形容词、“我认为”等主观表达。
- 结尾：正文分析完成后直接进入“参考文章及链接”，不附加独立建议段。

可使用的过渡句：

- “舆情要点聚焦：”
- “舆情焦点集中在三条链路：”
- “舆情焦点集中在三个层面：”
- “通过这一事件可以看到：”

## 标题要求

- 单行，15-35 字。
- 含问题意识、警示意味或价值判断。
- 可使用“反映……”“折射……”“警惕……”“如何撬动……”“会被带飞吗”等表达。
- 避免平铺直叙的新闻式标题。

## 议题类型与结构选择

| 议题类型 | 适用结构 | 参考范文 |
|----------|----------|----------|
| 民生治理 | 事件事实 + 规则争议 + 公共服务反思 | 房东税、4 娃高铁 |
| 政策落地与解读 | 政策内容 + 支持/反对/理性讨论 | 房东税 |
| 行业反思 | 个案事实 + 行业机制 + 治理缺口 | 医生跳楼 |
| 公共安全事件 | 伤亡/处置事实 + 风险链路 + 监管责任 | 香港大埔火灾 |
| 司法判决回顾 | 判决结果 + 公众期待 + 司法专业传播 | 祖孙三人案 |
| 文化现象 / 文旅观察 | 现象描述 + 情绪价值 + 城市治理或消费趋势 | 鸡排哥 |
| 涉外 / 涉港澳台议题 | 官方口径 + 外部反应 + 舆论引导 | 涉台议题范文 |
## 敏感议题处理原则

### 司法案件

- 未定罪当事人使用“涉嫌”“疑似”等表述。
- 已判决案件按判决书或法院通报表述。
- 避免替代司法机关作事实认定。
- 对精神疾病、未成年人、性侵、家庭暴力等议题保持克制，避免细节猎奇。
- 如果公众情绪强烈，应区分“公众期待”和“司法裁量专业性”。

### 港澳台议题

严格对齐央媒和官方口径。

| 错误/中性表述 | 标准表述 |
|----------------|----------|
| 台湾总统 / 台湾领导人 | 台湾地区领导人 |
| 台湾政府 | 台湾当局 |
| 台湾立法院 | 台立法机构 |
| 台湾 / 台湾岛 | 岛内 / 台湾地区 |
| 中华民国 | 不使用，改为“台湾地区” |
| 台独 / 一中一台 / 两国论 | 必须加双引号：“台独”“一中一台”“两国论” |
| 香港 / 澳门（与外国并列时） | 中国香港 / 中国澳门 |

### 涉外议题（一般国际事件，不涉港澳台）

- 事实层只使用中国官方发布（外交部/驻外使领馆表态、政府声明）及 S 级媒体
  报道；外部消息（外媒、外国政府、国际组织）须注明具体媒体或机构名称，
  不得笼统写作“外媒报道”。
- 涉我立场表述严格对齐外交部口径，不自行补充定性。
- 外部批评或争议观点仅在“外部反应”部分呈现，点明来源，不与中方立场
  并列对等。
- 未与中国建交地区、存在领土或主权争议的事项，不得自行表述立场，只转述
  官方表态。
- 引用外媒时，优先使用其官方中文版（如 BBC 中文网、联合早报中文网）或
  中国媒体转引稿；转引内容标注“转引自 XX”。
- 人名、机构名采用官方译名，首次出现附原文。

### 民族宗教议题

- 使用官方通报和权威媒体表述。
- 避免扩大化、标签化和群体归因。
- 对未经证实的冲突信息不得写入事实部分。

### 公共安全事件

- 伤亡数字以官方通报或权威媒体最新报道为准，并注明截至时间。
- 区分事故原因、初步调查、公众质疑和制度反思。
- 不传播未经核实的视频截图、网传名单、个人隐私。

## 常用表达

- “相关讨论从情绪表达逐步转向公共治理议题。”
- “该事件折射出规则执行与公众感受之间的张力。”
- “舆论并非单纯聚焦个案本身，而是延伸至制度安排与责任边界。”
- “在信息仍待进一步披露的情况下，相关表述应保持审慎。”
- “公众关注的核心不止于事件结果，也包括程序透明和回应效率。”

## 范文使用规则

撰写新报告时按以下顺序使用 `references/examples.md`：

1. 判断议题类型。
2. 匹配最接近的 1-2 篇范文。
3. 复用其结构骨架、过渡句式和分析逻辑。
4. 填入本次检索得到的真实信源、事实、数据和链接。
5. 不得套用范文中的占位 URL、人名、地名或脱敏事实。
